# Starter pack README

Original: [README.docx](starter-readme.docx).

Here's a potential starter kit to help you get going. You're not limited to these files: bring in other data, explore different sources and choose your own approach.

KBO: business data from Schoten

The KBO/ folder contains 1,000 real enterprise and establishment records from Digitaal Vlaanderen's public VKBO service, downloaded on 7 September 2026.

schoten-kbo-1000-2026-09-07.csv — Start here for names, registry numbers, addresses, activity fields and coordinates.

schoten-kbo-1000-2026-09-07.geojson — The original response, including all available fields and map coordinates.

source-metadata.json — The source URL, download date, licence and link to retrieve more records.

A few things to explore: this is only part of Schoten's register; some fields and parent enterprises are missing; businesses can share addresses; and some coordinates need checking. Import registry numbers as text to keep their leading zeros.

RAG: documents to get started with

The RAG/ folder contains nine PDFs: Schoten's market, terrace and fee regulations; VLAIO's business-startup guide; FAVV guidance and a federal decree; the Antwerp innovation-fund regulation; and an Omgevingsloket guide.

You can use these documents as a starting collection and add others that fit your idea. Check dates and which municipality a document applies to. Files marked HISTORICAL- are older background material. The collection is incomplete, and extracting PDF text can lose formatting or context.

Sources
